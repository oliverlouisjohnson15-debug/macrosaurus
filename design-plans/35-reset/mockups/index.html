Macrosaurus · Reset

Three directions for the same layout. C is the proposal that combines B with the Game Boy Color identity. Both use one hero per screen, rows instead of boxed cards, one prompt and at most one sentence of help. The proposed tab set (Today · Food · + · Train · Progress) is shown and still needs your approval. Each frame is a real 390×844 page, so you can scroll inside it.

C

Handheld (proposed)

B's calm with the Game Boy Color identity carried in the details. Windows have notched pixel corners, meters are HP bars, the buddy talks in a GBA dialogue box, and a ▶ cursor marks the active tab. Pixel numerals are kept for the numbers you track. All UI text is IBM Plex Sans at 11px or more. All six screens pass Impeccable's 59-rule detector with zero findings, in light and dark.

A

Paper, restrained

The Paper Terrarium kept and quietened. The purple bars, ink and gold stay. The hero is the only inked card on each screen, and everything else is rows on paper under small pixel labels. Silkscreen is kept for numbers, labels and chrome.

B

Clean base, pixel accents

A calm modern base in Plex Sans with no frames or coloured bars. Purple becomes an accent. Pixel art appears only in the hero numeral and the buddy, which keeps the game feeling like the game.
